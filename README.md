# Расписание

Планировщик школьного расписания для учителя. Тёмная тема Tokyo Night,
недельная сетка, конкретные даты вместо абстрактной недели, печать,
работа с телефона.

```bash
npm install
npm run dev
```

Открыть `http://localhost:5173`.

---

## Что умеет

**Два уровня расписания.** Постоянное расписание («по понедельникам вторым
уроком алгебра») и то, что реально происходит в конкретную дату — замены,
отмены, темы уроков, перенос времени. Правка одного дня не трогает шаблон,
правка шаблона не стирает темы уроков.

**Три режима.** Неделя — сетка со звонками и итогами дня. День — список
с отметкой текущего урока и окон. Шаблон — постоянное расписание.

**Урок.** Предмет, класс, кабинет, тема, личная заметка, своё время на
конкретный день. Предмет можно создать прямо в форме. Правый клик или долгое
нажатие открывает меню: копировать, отменить на день, вернуть как в шаблоне,
убрать из расписания.

**Календарь.** Каникулы, праздники и особые дни диапазоном. В отмеченные дни
шаблон не разворачивается, но разовое занятие добавить можно.

**Данные.** Автосохранение в браузере, отмена действий (Ctrl+Z), экспорт
в CSV и календарь `.ics`, резервная копия JSON и восстановление из неё.

**Печать.** Светлая тема, A4 landscape, интерфейс скрыт, личные заметки
на бумагу не идут.

**Чат сбоку.** Кнопка в правом нижнем углу: выбор между Telegram-ботом и
помощником, который отвечает на вопросы по приложению. Помощник работает через
серверную функцию `api/chat.js` — ключ Anthropic живёт в переменных окружения,
в браузер не попадает. Без ключа виджет показывает, что помощник не подключён.
В печать чат не идёт.

### Горячие клавиши

| | |
|---|---|
| `←` `→` | предыдущая / следующая неделя (в режиме «День» — день) |
| `T` | сегодня |
| `1` `2` `3` | неделя / день / шаблон |
| `Ctrl+Z` | отменить, `Ctrl+Shift+Z` — вернуть |
| правый клик, долгое нажатие | меню урока |

## Как устроено

```
src/
├── lib/
│   ├── datetime.js    даты и время без ловушек UTC
│   ├── schedule.js    наложение шаблона, дат и отметок дня
│   ├── export.js      CSV, ICS, JSON, текст для мессенджера
│   ├── storage.js     localStorage — единственное место, знающее о хранилище
│   └── palette.js     цвета предметов
├── state/
│   ├── scheduleReducer.js   правки + история для Ctrl+Z
│   └── ScheduleContext.jsx  провайдер, автосохранение, уведомления
├── components/        экраны и интерфейсные примитивы
└── data/seed.js       пример расписания при первом запуске

api/chat.js            серверная функция чата: ключ Anthropic не покидает сервер
supabase/schema.sql    таблицы, RLS, сборка расписания, выборка напоминаний
docs/ROADMAP.md        этапы 3–8 и где обычно ломается
```

### Модель данных

```
bells      сетка звонков
subjects   предметы
template   постоянное расписание: день недели × звонок
overrides  конкретная дата: замена, отмена, тема, своё время
days       каникулы, праздники, особые дни
```

Экран показывает результат наложения `template + overrides + days`.
Тема урока принадлежит дате, а не дню недели — в этом весь смысл разделения.

### Даты и время

Дата — строка `YYYY-MM-DD` в местном времени, время — `HH:MM`.
`Date.toISOString()` для дат не используется: он переводит в UTC и в Москве
отдаёт вчерашний день для всего, что раньше трёх ночи. Момент во времени
собирается только на сервере, из пары «дата + время» и таймзоны пользователя.

## Дальше

`docs/ROADMAP.md` — деплой на Vercel, Supabase с RLS, Telegram-бот, напоминания
по cron. Схема базы готова и проверена: `supabase/schema.sql`.

Секреты в репозиторий не попадают. Шаблон переменных — `.env.example`;
всё, что начинается с `VITE_`, попадает в браузер, остальное живёт на сервере.

## Стек

React 19 · Vite 8 · Tailwind CSS 4. Без внешних зависимостей в рантайме,
иконки нарисованы в проекте.
