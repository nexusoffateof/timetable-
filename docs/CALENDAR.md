# Google Календарь

Расписание попадает в Google Календарь одной командой в чате Claude:

```
/calendar
```

Что где живёт:

```
calendar/scenario.json      сценарий — что должно стоять в календаре
scripts/calendar-plan.mjs   сценарий → план событий, без сети
.claude/commands/calendar.md что делает команда: план, сверка, запись
```

Скрипт ничего не пишет: он печатает план и проверяется локально. Запись
делает Claude через коннектор Google — там, где нужны права на календарь.

---

## Сценарий

`calendar/scenario.json` — обычный JSON, правится руками за минуту.

```json
{
  "calendar": {
    "calendarId": "primary",
    "timezone": "Europe/Minsk",
    "marker": "timetable-sync",
    "reminderMinutes": 15
  },
  "period": { "from": "2026-09-01", "to": "2026-12-25" },

  "bells": [{ "n": 1, "start": "08:30", "end": "09:15" }],

  "subjects": {
    "Алгебра": { "color": "#7aa2f7", "room": "212" }
  },

  "template": {
    "mon": [{ "bell": 1, "subject": "Алгебра", "class": "8А" }]
  },

  "skip":  [{ "from": "2026-11-02", "to": "2026-11-08", "label": "Каникулы" }],
  "extra": [{ "date": "2026-09-25", "start": "15:00", "end": "16:30", "title": "Собрание" }]
}
```

| Поле | Смысл |
|---|---|
| `calendarId` | `primary` или адрес отдельного календаря из `list_calendars` |
| `marker` | подпись в описании события — по ней команда узнаёт свои события |
| `reminderMinutes` | напоминание, число или список; `null` — как в календаре |
| `bells` | сетка звонков, номер и время |
| `subjects` | цвет и кабинет по умолчанию; hex переводится в ближайший цвет Google |
| `template` | постоянное расписание: `mon`…`sun`, `пн`…`вс` или `1`…`7` |
| `skip` | дни без уроков: `date` либо `from` и `to` |
| `extra` | разовое событие, каникулы ему не мешают |

В уроке можно переопределить что угодно из умолчаний предмета:
`room`, `start`, `end`, `note`, `colorId`, `title`, `reminderMinutes`.

---

## Как это ложится в календарь

Постоянный урок — одно повторяющееся событие на пару «день недели × звонок»,
каникулы вычитаются через `EXDATE`. Четверть — это два десятка событий,
а не шестьсот: календарь остаётся редактируемым, а не свалкой.

Подпись в описании выглядит так:

```
timetable-sync · ср-1 · v=399cb054
```

Ключ говорит, какой это слот, хэш — не изменился ли он. Совпал — событие
не трогают, разошёлся — пересоздают. Событие без подписи команда не тронет
никогда, в том числе при `очистить`: чужие встречи в безопасности.

Пересоздание вместо правки — потому что `update_event` в коннекторе не умеет
менять повторы, а меняются как раз они.

## Команды

```
/calendar                                весь период из сценария
/calendar неделя                         текущая неделя
/calendar следующая неделя
/calendar месяц 2026-10
/calendar с 2026-09-01 по 2026-10-31
/calendar проверить                      показать разницу, ничего не писать
/calendar очистить                       снять всё своё за период
/calendar из копии ~/Загрузки/backup.json
```

Локально, без чата и без календаря:

```bash
node scripts/calendar-plan.mjs            # план человеку
node scripts/calendar-plan.mjs --json     # план машине
node scripts/calendar-plan.mjs --week --flat
```

## Из приложения

`Настройки → Данные → резервная копия` даёт JSON со всем расписанием.
`/calendar из копии <путь>` разворачивает его по дням: с заменами, темами,
отменёнными уроками и перенесённым временем. Повторов здесь нет — у каждой
даты своя правда, ради этого разделения приложение и затевалось.

Сценарий в этом режиме отдаёт только блок `calendar`: куда писать,
какая таймзона, какой маркер.

## Автоматически

Команда идемпотентна: гонять её можно сколько угодно, лишнего не появится.
Отсюда автозапуск — например, каждое воскресенье в 20:00, чтобы горизонт
всегда был на месяц вперёд. Попроси Claude: «заведи Routine — воскресенье
20:00, `/calendar месяц`». Правило одно: сценарий правится в репозитории,
календарь — только командой. Правка события руками в Google переживёт
синхронизацию лишь до первого расхождения хэша.

---

## Если что-то не так

**Событий нет, ошибок нет.** Проверь `period`: скорее всего он в прошлом
или не пересекается с аргументом команды.

**События уехали на час.** `calendar.timezone` должен быть IANA-именем
(`Europe/Minsk`), а не смещением. Время в сценарии — настенное: 08:30
остаётся 08:30 при любом переходе на летнее время.

**Дубли.** Значит, у двух слотов совпал ключ — такого не бывает при валидном
сценарии, скрипт ловит два урока в один звонок. Сначала `/calendar очистить`,
потом `/calendar`.
